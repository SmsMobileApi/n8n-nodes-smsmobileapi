# Changelog

## 0.1.0 — 2026-11-26

- Initial SMSMobileAPI community nodes for n8n.
- Send SMS with an optional connected mobile and SIM selection.
- Read received SMS, missed calls, incoming calls, outgoing calls, and connected mobile status.
- Trigger workflows when new SMS or call records are synchronized.
- Authenticate with a protected SMSMobileAPI API key.
